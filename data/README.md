# Data directory

`mimic_demo.sqlite` is the prepared four-table classroom database built from the official MIMIC-IV Clinical Database Demo v2.2.

Official data DOI: https://doi.org/10.13026/dp1f-ex47

The database contains authentic deidentified data. Keep the original dataset citation and license notice with every distributed copy. Do not use this 100-patient convenience subset for prevalence or clinical model-performance claims.
